## 翻译要求（严格遵守）

1. **忠实优先**。这是心理测量题项，不是文学翻译。术语、程度、方向都不能改。
2. **保留第一人称语气**。多数题项是「I feel…」「I am…」的自我描述，中译要读起来像自评，
   不要写成第三人称陈述或学术定义。
3. **不能把反向题译成反向题的反面**。例如 `I am not easily bothered by things.`
   必须译出「不容易被事情烦扰」，不能译成「容易被事情烦扰」。
4. **不许把英文原文内嵌进 `zh`**。英文原文由条目自己的 `en` 字段承担，界面上与本字段
   **并列显示**（R2 三部分并列：① 英文原文 / ② 中文翻译 / ③ 本地化讲解）。
   `中文（English original）` 这种写法**已废止**（2026-10-04 R6 统一删除 29 处）——
   它会让英文出现在**用户可见的题面**里，也把同一信息写了两遍。
5. **非字面表达不得直译——译其含义。**（2026-10-07 新增，用户裁决）
   英语**习语、比喻性动词、固定搭配、文化特定说法**（体育/军事/宗教来源的比喻）都不许把
   字面内容词逐个搬进中文，必须译出它**实际的意思**；必要时用中文里对应的说法。
   - ❌ `You need to step on some toes to get what you want in life.`
     → 「在生活中，你必须踩到一些人的脚趾，才能得到自己想要的。」（**逐字直译**，中文里没有
     这个说法，读者会理解成真的去踩别人的脚）
   - ✅ 「在生活中，想要得到自己想要的，就难免要得罪一些人。」
     （`step on someone's toes` 意为**冒犯、越界、为达目的而损害他人利益**）
   - 同类：`tip of the iceberg`、`down in the dumps`、`have a sharp tongue`、`hold a grudge`、
     `turn my back on others`、`in the same boat`……
   - **自检**：把这句中文单独念一遍——如果中文语境里不成立、或读者会理解成字面意思，就是缺陷。
     凡命中已知习语的条目，由 `tools/check/check_idiom_translation.py` 守卫（会因字面词而报错）。
6. **读起来不像中文也是缺陷**。翻译腔、逐词对应、生硬搭配（如 `Cheat to get ahead.` →
   「为了领先别人，我会采用作弊的方式」）即使意思没错，也算缺陷——用户的原话就是「不像中文」。
   宁可拆句、换个说法，也不要留一句念不顺的译文。
7. **术语一致性**：同一批里同一个英文词必须用同一个中文词。常见对照：
   - facet → 面向；domain → 域；item → 题项
   - anxiousness → 焦虑；withdrawal → 退缩；anhedonia → 快感缺失
   - impulsivity → 冲动性；irritability → 易激惹；hostility → 敌意
   - somatic → 躯体；dissociation → 解离；psychoticism → 精神病性
   - mania → 躁狂；grandiosity → 夸大；deceitfulness → 欺骗性
   - suicidal ideation → 自杀意念；substance use → 物质使用
8. **注释**：每题一句，说明**这题实际在问什么**（不是复述题面）。
   若该题有明显的中文语境误读风险（如 "grouchy" 不等于"生气"、"nervous" 不等于"紧张到慌"），
   用一句话点出差别。控制在 60 字内。
